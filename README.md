# QuickAdd for Reminders

A small macOS menu bar app for quickly creating Apple Reminders from anywhere.

Press **Control + Command + A** to open QuickAdd, type your reminder, and save it without opening the Reminders app.

## Features

- Global Control + Command + A shortcut
- Apple Reminders lists
- Natural-language dates and times
- Recurring reminders
- `/List` shortcuts
- Priority
- Notes
- Keyboard-first workflow
- Remembers window position and last-used list

## Requirements

- macOS
- Apple Reminders

QuickAdd is a standalone macOS app and is separate from the Add to Reminders Chrome extension.
